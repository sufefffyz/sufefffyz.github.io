# Yuzhang Fei — academic homepage

Website: https://sufefffyz.github.io/

This site uses the official static HTML version of [Minimal Light](https://github.com/yaoyao-liu/minimal-light), pinned at `1ea07f39518ac44644406380c83da6f89037c4fc`.

## Theme and content

The upstream HTML structure, layout, colors, responsive rules, avatar styling, and light/dark mode are retained. All rules in `assets/css/style.css` match the upstream file; only its Google Fonts imports are replaced with a local import. Crimson Pro, Ubuntu Mono and Font Awesome 5.11.2 are served locally. Original licenses are included.

The name, affiliation, doctoral status, advisor, research interests and avatar come from the owner's GitHub profile. The owner supplied the OpenReview registration email. The theme's sample publications, CV, news and unrelated profile links are omitted, as is its example analytics configuration.

## Editing

- Edit personal content in `index.html`.
- Replace `assets/img/avatar.png` to change the avatar.
- Keep all static assets, font licenses and `LICENSE-Minimal-Light.txt` when publishing.
- `template-source.json` records the upstream version and original checksums.

## Publishing

Publish only this homepage directory to `sufefffyz/sufefffyz.github.io`, on the `main` branch. GitHub Pages serves the repository root. Do not upload the containing research workspace.

After publishing, check GitHub Pages deployment status and verify that the public page displays the name, affiliation and `yuzhang.fei@ruc.edu.cn` without signing in.
